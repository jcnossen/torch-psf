# PSF estimation from dense blinking movies (SOFI / dense SMLM): simulation study and first real data

Branch `sofi-psf`. Brief: `sofi_psf_brief.md`; theory: `psf_estimation_theory.md` sections 2, 5, 6. Code:
`torch_psf/sofi/` (library), `study/sofi/` (scripts; every number below is regenerated by the script named next to
it; generated output goes to `~/sofi_psf_out`, override with `SOFI_OUT`).

## Summary

- The second-order cross-cumulants G(r, d) = Cov(F_r, F_{r+d}), 0 < |d| <= 5 px (40 separations), of a dense blinking
  movie determine the Zernike aberrations (Noll 5-21) to **0.2-0.8 mλ rms per mode** (CRLB, 10 x 10 um, 10^4 frames,
  density profiled out as an arbitrary non-negative map), nearly independent of the emitter density (10-500 /um^2).
  Shot noise, uncorrelated read noise and the background do not enter G for d != 0.
- The only requirement on the sample is independent blinking. Both permanently dense SOFI movies and dense SMLM
  movies work in principle.
- The prototype estimator (`SOFIEstimator`) recovers 12 mλ rms of random aberrations to **0.9-2.6 mλ** in the base case
  (1-4x the CRLB). Bleaching (50 %) and 2 px of uncorrected drift cost little. Correlated (row) read noise biases the
  result by ~10 mλ unless a dark movie is subtracted. Dense SMLM blinking is ~10x off its CRLB (open).
- First real data (EPFL Tubulin-COS7-Flip565 2D SOFI): repeatable within an ROI (split-half 3-8 mλ rms per mode) and
  consistent trefoil (Z9 +40..+115 mλ) and astigmatism (Z6 -50..-75 mλ) over the field. Other modes differ between
  ROIs by 20-56 mλ: either field dependence or a sample-dependent bias (to be resolved).

## 1. Simulator and accumulator (steps 1, 2)

- `sofi.blink`: continuous-time Markov blinking (off / on / optional long dark state / optional bleaching), Euler
  sub-steps, frame-integrated on fraction. `trace_stats` gives the moments the noise model needs (var, alpha = sum_tau
  r(tau)^2, beta, k3, c4).
- `sofi.simulate`: dense movies. Emitters extend (Q-1)/2 outside the frame. Poisson / EMCCD gamma noise, read noise,
  row / column noise, linear drift, bleaching.
- `sofi.cumulants.CumulantAccumulator`: streaming per-block (default 500 frames) zero-lag covariances for the half-set
  of separations, optional lag-1, block bootstrap.
- `validate_accumulator.py` (T = 20000, 40 x 40): relative residual of G against the analytic expectation 0.030.
  Global scale 0.9934 vs the predicted block-mean bias 1 - (beta - 1)/(n_block - 1) = 0.9952; per-separation scale
  0.990-1.0015. The patch matrix and the convolution model agree to 9e-16.

## 2. Noise model and Fisher information (step 3)

- `sofi.fisher.noise_cov`: analytic covariance of the G entries: Wick (Gaussian) term with the lagged covariance
  C(tau) = r(tau) S + delta N, the shot-noise x third-order blinking terms (x F2 = 2 for EMCCD) and the non-Gaussian c4
  term.
- `validate_noise.py` (K = 256 movies, T = 2000, P = 10): chi^2/dof 1.005 (SOFI), 1.025 (dense SMLM), 1.002 (SOFI
  EMCCD). Median Monte-Carlo / model variance ratio 0.99 / 0.98 / 1.00; with the Gaussian part only, dense SMLM gives
  1.12 (the non-Gaussian term matters for sparse-duty blinking). Block bootstrap / model ratio ~0.96.
- `fisher_sweep.py`: J = A_w^T (I - P_B) A_w after whitening; the density is profiled out (arbitrary non-negative map,
  conservative; or known support, optimistic). A common z shift (dz) is a nuisance (defocus gauge). Bulk information
  per px^2 from two patch sizes; scaled to 10 x 10 um and 10^4 frames. Optics: NA 1.49, n_imm 1.518, n_med 1.33,
  680 nm, 108 nm px.

CRLB (mλ rms per mode, Noll 5-21, arbitrary density):

| case | range over modes |
|---|---|
| base (thin sample, in focus, 0.05 rms aberration, SOFI blinking duty 0.3, 80 /um^2) | 0.2-0.8 |
| density 10 .. 500 /um^2 | 0.3 .. 0.6-1.1 |
| fast blinking (t_on 0.5 frame) | 0.4-1.2 |
| dense SMLM (duty 0.02, long dark state, 400 /um^2) | 0.25-0.66 |
| dense SMLM + astigmatism 0.1 λ | 0.1-0.3 |
| thick sample z 0-0.4 um / 0-0.8 um | up to 1.2 / 1.5 (known support: 0.2-0.6) |
| z 0-0.8 um + astigmatism | 1-3.3 |

- Patch size: 16->20 and 20->24 px agree to ~10 % (`fisher_sweep.py --check-sizes`). The rank cut-off of the density
  projector (1e-6 .. 1e-14) changes the bounds by < 10 % (`tol_check.py`).
- **Symmetry:** with real pupil amplitude and an index-matched sample in focus the even modes (and dz) have no
  first-order signal (infinite CRLB; confirmed with n_med = 1.518). With n_med = 1.33 and emitters at the coverslip,
  the supercritical-angle light (complex Fresnel coefficients) breaks the symmetry and the even modes become
  determinable. An astigmatic bias or defocus also breaks it.
- The local CRLB does not capture the global twin (sign) ambiguity of the even modes; a start with a known bias
  (e.g. the cylindrical-lens astigmatism) selects the branch.

## 3. Estimator (step 4)

`sofi.fit.CumulantFit`: weighted least squares on G. The non-negative density on a sub-pixel grid (os = 2) is fitted by
FISTA, and the Zernikes + dz by Levenberg-Marquardt (jvp Jacobians), alternating. Weights are 1 / (smoothed block-bootstrap
variance). `SOFIEstimator` (same interface as ZStackEstimator / InSituEstimator) streams the movie, optionally
subtracts the covariances of a dark movie, and returns a VectorialPSF.

`estimate_test.py` (64 x 64 px = 47.8 um^2, 10^4 frames, truth 0.05 rms total = 12 mλ, error = rms over Noll 5-21,
seeds 0 / 1 / 2):

| case | error (mλ) |
|---|---|
| base | 0.89 / 2.58 / 1.27 |
| emitters off the density grid | 0.94 / 2.77 / 1.28 |
| defocus 0.4 um | 2.49 / 1.64 / 2.43 |
| astigmatism 0.10 λ | 2.29 / **10.8** / 1.31 |
| off grid + astigmatism | 2.15 / **10.7** / 1.44 |
| bleaching 50 % | 0.95 / 3.19 / 1.73 |
| drift 2 px (uncorrected) | 1.67 / 3.16 / 1.12 |
| row read noise 3 e- (no dark movie) | 12.8 / 7.9 / 10.5 |
| dense SMLM | 5.9 / 6.3 / 8.0 |

- Seed 1 is worse in every case and its fitted dz is always 6-15 nm. That is likely dz trading against spherical; in
  the astigmatic cases it converges to a wrong solution. Multi-start or a dz prior should fix it.
- Row noise: the expected bias. `SOFIEstimator(dark=...)` subtracts it; not yet tested.
- Dense SMLM is ~10x off the CRLB. Suspects: bootstrap weights with long dark-state correlations (500-frame blocks
  vs t_dark = 200), FISTA convergence with very sparse density, block-mean bias.
- `tests/test_sofi.py`: recovers coma within 4 mλ on a 40 x 40, 4000-frame simulation (~40 s on GPU).

## 4. Real data: EPFL SRM hub, Tubulin-COS7-Flip565-2D

Grussmayer et al., ACS Nano 2020, Fig. 1: 8000 frames, 500 x 500 px, ORCA Flash 4.0, 20 ms, 108 nm px, Nikon
60x / 1.27 NA water, Flip565 in 50 % glycerol. The dataset page is gone; the file is still at
`https://srm.epfl.ch/datasets/real/LBEN/SOFI/Tubulin-COS7-Flip565-2D/Tubulin_SOFI_2D_flip.tif` (same pattern for the
Biplane, Multiplane and Spectral-Cumulant-MC sets). Movie used in ADU without a camera model (a constant offset does
not enter G; the gain only scales it). Assumed optics: NA 1.27, n_imm 1.33, n_med 1.40, 600 nm.

Data: offset ~100 ADU, slight bleaching (frame mean 133 -> 128 ADU), lag-1 temporal correlation 0.59 on bright
pixels (emitters stay on for more than one frame), neighbour correlation 0.01 on the background (no correlated
camera noise).

`epfl_sofi2d.py` (96 x 96 px ROIs, all frames; `--frames` for the halves), mλ:

| ROI (y0, x0) | dz (nm) | Z5 | Z6 | Z9 | Z10 | Z14 |
|---|---|---|---|---|---|---|
| (82, 82) | +89 | +16 | -75 | +113 | +36 | +29 |
| (82, 322) | -56 | +25 | -69 | +89 | -87 | -30 |
| (202, 202) | -51 | -54 | -22 | +86 | -68 | +84 |
| (322, 82) | -10 | +91 | -66 | +52 | +26 | -15 |
| (322, 322) | -10 | +61 | -48 | +38 | +46 | +4 |

- Split halves (frames 0-4000 vs 4000-8000): rms difference per mode / sqrt 2 = 3-8 mλ. The exception is ROI (82, 322),
  where one half took the other dz branch (+53 vs -59 nm): 14 mλ.
- Spread between ROIs (rms over the 5 ROIs): Z5 49, Z10 56, Z14 40, Z9 27 mλ; Z7, Z8, Z12, Z13, Z16, Z17, Z19, Z20 < 10 mλ.
- So the differences between ROIs are not noise. Either the aberrations depend on the field, or the fit is biased
  by the sample: the centre ROI lies under the dense cell body, where a thin-sample model is least valid. Open; checks:
  a finer ROI grid (a smooth map means field dependence), more z layers, and the sensitivity to the assumed optics.

## 5. Side test: PSF-aware SOFI reconstruction

`sofi.reconstruct.reconstruct` (`SOFIEstimator.reconstruct()`): the fitted density on an os = 4 grid, with the
estimated PSF, positivity and optional l1 / smoothness priors; `sofi2_xc` is standard cross-cumulant SOFI2
(midpoint virtual pixels, Gaussian distance factor, optional Fourier reweighting).

- Simulation (`recon_sim.py`, line pairs, 0.07 λ rms aberration, 8000 frames). Contrast is 1 - midpoint / line value;
  > 0 means the pair is resolved:

  | method | 160 nm | 200 nm |
  |---|---|---|
  | SOFI2 | -0.24 | -0.04 |
  | SOFI2 + Fourier reweighting | -0.07 | +0.25 |
  | PSF-aware, true PSF | +0.33 | +0.90 |
  | PSF-aware, aberration-free PSF | +0.26 | +0.77 |

  The aberration-free PSF also gives ringing side lobes. Nothing resolves 120 nm or less.
- Real data (`epfl_sofi2d_recon.py`): the PSF-aware images are sharper than the aberration-free-PSF version but
  break filaments into segments (positivity-only deconvolution on a fine grid). Fourier-reweighted SOFI2 looks
  cleanest. A uniform smoothness prior trades the gain for blur (0.03 too strong, 0.003 close to none). Making it
  competitive needs a Wiener-like prior in the same model; experimental, not pursued.
